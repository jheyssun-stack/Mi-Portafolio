PROYECTO ACADÉMICO · DESARROLLO DE APLICACIONES

Una herramienta para aprender y calcular.

Aplicación web interactiva desarrollada como proyecto académico de Desarrollo de Aplicaciones. Permite calcular el área y perímetro de diferentes figuras geométricas.

El usuario selecciona una figura, ingresa sus medidas y obtiene el resultado acompañado de la fórmula utilizada.

El proyecto también incorpora una herramienta para resolver problemas mediante el Teorema de Pitágoras, con validación de datos y selección de unidades de medida.

React TypeScript Vite Tailwind CSS SVG
01 6 figuras geométricas
02 7 unidades de medida
03 Área y perímetro
04 Teorema de Pitágoras
