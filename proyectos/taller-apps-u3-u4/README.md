# Evidencias académicas · Taller II

Este directorio conserva las guías complementarias de las semanas 1–8 y las evidencias de las semanas 9–16 del proyecto **JHEYVX TECH**.

La aplicación que corresponde al sílabo es una aplicación de escritorio en Java Swing, con JDBC/H2, inventario, ventas, transacciones, servicio TCP multihilo y pruebas automatizadas. El código editable está en `../jheyvx-tech-desktop/`. La ficha y las descargas están en `../../aplicacion/desarrollo-u3-u4/`.

Las semanas 9–16 incluyen un informe HTML/Markdown y una infografía SVG cada una. El portafolio web sirve como presentación y descarga: Java Swing se ejecuta en una computadora con Java 8 o posterior y no dentro del navegador. No requiere VPS ni cuenta de base de datos en la nube.
