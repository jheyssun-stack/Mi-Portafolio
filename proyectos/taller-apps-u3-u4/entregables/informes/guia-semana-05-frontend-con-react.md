## Desarrollo ampliado

Un componente React representa una parte visual con entradas explícitas. Props fluyen desde el padre; `useState` mantiene estado interactivo; eventos actualizan ese estado. En formularios controlados, el valor de cada campo coincide con el estado y la validación muestra mensajes junto al campo. `react-router` relaciona URL con vistas. No guardes secretos de servidor en código React: el navegador puede inspeccionarlo.
