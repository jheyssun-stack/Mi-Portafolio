## Desarrollo ampliado

Java compila el código fuente a bytecode ejecutable por la JVM. Una clase encapsula campos y métodos; constructor inicializa el objeto. Mantén campos privados y valida cambios con métodos. La herencia expresa una especialización; las interfaces permiten distintos comportamientos sin acoplar la clase concreta. Usa `List` para secuencias y `Map` para búsquedas por clave; captura excepciones concretas y no ocultes el error. En Maven, `pom.xml` declara dependencias; `mvn test` ejecuta pruebas y `mvn package` crea el artefacto.
