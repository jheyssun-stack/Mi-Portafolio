Desarrollo ampliado

El flujo Full-Stack es navegador React → petición HTTPS/JSON → API de Spring Boot → MySQL. El servidor valida y ejecuta reglas, y responde con código HTTP y JSON. JDK provee compilador y runtime (verifica java -version); NetBeans es el entorno de edición; Maven resuelve bibliotecas; Workbench administra MySQL; Node/npm ejecutan herramientas de frontend. Comprueba cada instalación por separado y registra versiones reales de tu equipo, sin copiar versiones supuestas.
