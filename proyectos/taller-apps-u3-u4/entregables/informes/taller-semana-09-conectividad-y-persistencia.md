# Semana 09 · JDBC y conexión relacional

**Proyecto:** JHEYVX TECH · aplicación de escritorio Java Swing

## Propósito y desarrollo

Conectar la aplicación de escritorio con una base relacional usando el controlador JDBC. Se configuró H2 local y una capa de acceso que abre y cierra conexiones mediante try-with-resources.

## Flujo técnico

`JDBC Driver → DriverManager → Connection → PreparedStatement → ResultSet`

## Resultado y evidencia

La app inicia la base local y prepara las tablas de productos, ventas y detalles.

## Herramientas y componentes

Database.java · database.properties · H2 · JDBC
