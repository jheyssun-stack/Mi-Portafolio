TECH

Sistema de inventario y ventas construido en Java Swing. Usa JDBC con base relacional local, registra operaciones de forma segura y separa la interfaz del servicio mediante una conexión cliente-servidor.

Qué incluye

01 / DATOS

Inventario conectado

Alta, edición, búsqueda y baja lógica con validación de precio y existencias.

02 / VENTAS

Registro transaccional

Calcula subtotales, revisa stock y registra la venta junto al descuento de inventario dentro de una transacción.

03 / ARQUITECTURA

Cliente y servidor

Servicio TCP local con pool de hilos y mensajes JSON; la interfaz Swing consume el servicio.

04 / PERSISTENCIA

Base local

H2 crea sus tablas al iniciar y conserva los cambios en la carpeta data.

05 / CONTROL

Validaciones y pruebas

Pruebas automatizadas de CRUD, reglas de negocio, rollback por stock insuficiente y comunicación TCP.

06 / ENTREGA

Ejecutable y código

JAR autocontenido y ZIP con fuentes, instrucciones, esquema SQL y pruebas.

Importante: esta es una aplicación de escritorio, no se ejecuta dentro de una pestaña del navegador. Descarga el JAR y ábrelo con Java 8 o posterior. El portafolio sirve para presentar y descargar el proyecto; no hace falta un VPS.
